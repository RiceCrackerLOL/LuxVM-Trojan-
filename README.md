# LuxVM Desktop AI Messenger

A fully standalone Windows desktop AI messenger app built with React, TypeScript, Electron, Vite, and GitHub Actions.

## Quick Start
1. Extract this ZIP archive directly into your GitHub repository root.
2. Commit and push all files to `main`.
3. Go to the **Actions** tab on GitHub to watch the automated build complete successfully under Node.js 22.
4. Download the `LuxVM-Windows-App` artifact from the run summary and run `LuxVM.exe`!
